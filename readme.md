\# Desarrollo de Software Científico



Repositorio del curso \*\*Desarrollo de Software Científico\*\*, orientado al diseño, implementación, validación, documentación y distribución de software computacional para resolver problemas científicos.



El curso integra conceptos de \*\*programación científica, ingeniería de software, computación científica y reproducibilidad\*\*, con énfasis en el desarrollo de herramientas que puedan ser utilizadas y reutilizadas en proyectos de investigación.



\---



\## 🎯 Propósito del curso



Desarrollar competencias para construir software científico \*\*correcto, reproducible, mantenible, documentado y reutilizable\*\*, aplicando buenas prácticas de ingeniería de software a problemas propios de las ciencias y la física computacional.



El curso busca superar el enfoque de "escribir código que funciona" para avanzar hacia la construcción de \*\*software científico de calidad\*\*.



\---



\## 🔬 ¿Qué entendemos por software científico?



El software científico comprende programas, bibliotecas y herramientas computacionales desarrollados para:



\* Resolver modelos matemáticos y físicos.

\* Realizar simulaciones numéricas.

\* Procesar y analizar datos científicos.

\* Implementar métodos numéricos.

\* Automatizar experimentos computacionales.

\* Visualizar resultados científicos.

\* Reproducir resultados de investigación.

\* Construir herramientas computacionales reutilizables.



Algunos ejemplos incluyen:



\* Solvers de ecuaciones diferenciales.

\* Métodos de integración numérica.

\* Simulaciones de sistemas dinámicos.

\* Métodos Monte Carlo.

\* Simulaciones de dinámica molecular.

\* Métodos de elementos finitos.

\* Procesamiento de datos experimentales.

\* Herramientas para análisis de señales.

\* Bibliotecas para física computacional.

\# 📖 Filosofía del curso



El desarrollo de software científico no termina cuando el programa produce un resultado.



Un software científico debe aspirar a ser:



> \*\*Correcto → Verificable → Reproducible → Documentado → Mantenible → Reutilizable\*\*



Por esta razón, el curso aborda tanto la \*\*ciencia computacional\*\* como las prácticas de \*\*ingeniería de software\*\* necesarias para transformar código científico en software que pueda ser utilizado por otros investigadores.

\# 📂 Uso del repositorio



Clonar el repositorio:



```bash

git clone https://github.com/USUARIO/Desarrollo-Software-Cientifico.git

```



Ingresar al directorio:



```bash

cd Desarrollo-Software-Cientifico

```



Crear un entorno virtual:



```bash

python -m venv .venv

```



Activar el entorno en Linux/macOS:



```bash

source .venv/bin/activate

```



En Windows:



```powershell

.venv\\Scripts\\activate

```



Instalar las dependencias:



```bash

pip install -r requirements.txt

```

\# 🌎 Reproducibilidad científica



Uno de los objetivos centrales del curso es comprender que la reproducibilidad no depende únicamente de publicar los datos o el código.



Un proyecto reproducible debe permitir que otra persona pueda:



1\. Obtener el código.

2\. Instalar las dependencias.

3\. Ejecutar los experimentos.

4\. Reproducir los resultados.

5\. Comprender el funcionamiento del software.

6\. Modificarlo y reutilizarlo.
